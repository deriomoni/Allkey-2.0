# Allkey-2.0
## Операционный слой

Знания, скиллы агента и карточки компаний живут в отдельном приватном репозитории со своей историей:
**[allkey-ops](https://github.com/deriomoni/allkey-ops)**. Сайт на него только ссылается и не хранит его содержимое.

Воркер модуля «Операции» (`ops-worker`, см. ТЗ в `allkey-ops/docs/tz-operations.md`) читает репозиторий с диска сервера
из `/opt/allkey-ops` и делает `git pull` перед каждым запуском.
