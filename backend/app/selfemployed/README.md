# Модуль «Договор с самозанятым» (selfemployed)

Автосоставитель договора с самозанятым лицом по 12 видам деятельности из
перечня (постановление Правительства РК от 21.11.2025 № 994, действует
с 01.01.2026).

Модуль **stateless**, как и кадровый: в БД ничего не пишется, документ
собирается в памяти, ИИН и ФИО приходят только в теле запроса — не в URL,
не в логах. Своих таблиц и моделей у модуля нет.

## Состав

| Файл | Что внутри |
|---|---|
| `profiles.py` | 12 профилей ОКЭД: название договора, предмет по умолчанию, тексты разделов 1, 3, 4, 6, срок уведомления о расторжении. `ORDER` задаёт порядок в справочнике |
| `builder.py` | контекст docxtpl, преамбула (RichText), раздел 5 (п. 5.2 — срок оплаты), реквизиты, `check()`, `render()`, `filename()` |
| `schemas.py` | pydantic-модели запроса (тело = словарь, который принимает `build_context`) |
| `router.py` | API, доступ через `require_service('selfemployed')` |
| `templates/dogovor_samozanyatyi.docx` | docxtpl-шаблон. **Руками не править** — генерируется `make_template.py` |
| `make_template.py` | сборка шаблона из кода (запускать при правке вёрстки) |
| `render_samples.py` | образцы по всем ОКЭД для вычитки: `python -m app.selfemployed.render_samples <каталог>` |

## Общие хелперы

Своих копий числовых и языковых функций в модуле нет — всё из кадрового модуля:

* числа прописью и разрядка — `app.personnel.helpers.numbers`
  (`ru_int_to_words`, `format_figures`, `pluralize_ru`);
* склонение ФИО руководителя и должности — `app.personnel.helpers.fio`
  (pymorphy3; `head_genitive`, `position_genitive` в `builder.py` — обёртки).
  Форма может передать готовые `head_name_gen` / `position_gen` — тогда они
  и подставляются, склонение не вызывается;
* проверка ИИН/БИН — `app.personnel.helpers.iin` (контрольная сумма, дата
  рождения, пол по 7-й цифре).

## API

Всё закрыто сервисом `selfemployed` (роли у сервиса пусты → видит только
администратор; открыть сотрудникам — выдать роль на экране «Доступы»).

| Метод | Назначение |
|---|---|
| `GET /api/selfemployed/okeds` | справочник для селекта: `code, name, kind, title, default_subject, notice_days` в порядке `ORDER` |
| `POST /api/selfemployed/check` | `{"warnings": [...]}` — предел 300 МРП, даты, ИИН/БИН, «___» в предмете. Генерацию не блокируют |
| `POST /api/selfemployed/generate` | договор .docx, имя файла по `filename(data)` |
| `POST /api/selfemployed/validate/iin` | проверка ИИН (хелпер personnel) — свой эндпоинт, т. к. `/personnel/validate/iin` закрыт сервисом `hr` |
| `POST /api/selfemployed/validate/bin` | проверка БИН/ИИН заказчика |

## Справочники в коде

`MRP` в `builder.py` — МРП на 1 января года: `{2026: 4325}`. **На новый год
добавить значение**, иначе `check()` предупредит, а в п. 5.1 вместо суммы
останется «300 МРП». Предел самозанятого — 300 МРП в месяц (п. 2 ст. 718 НК РК).

## Правила правок

* Шаблон проверяется **только реальным рендером**, не осмотром текста
  (правило проекта, см. `app/personnel/README.md` — там же про `{%tr %}`
  и про имена, затеняющие типы: дата договора называется `contract_date`,
  не `date`).
* Тесты: `pytest backend/app/selfemployed/tests`. `test_selfemployed.py`
  рендерит все 12 ОКЭД и проверяет, что в тексте не осталось `{` / `}`;
  `test_gating.py` прогоняет границу доступа (401/403/200) и API.
* ИИН/БИН в тестах — с верной контрольной суммой: проверки берутся
  из хелперов personnel, произвольные 12 цифр их не проходят.
