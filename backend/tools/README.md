# Оснастка прогона ситуаций

`probe.py` прогоняет произвольные ситуации через живую помогайку и печатает
вердикт в виде, который кладётся рядом с текстом консультации.

## Как запустить

```
cd backend
set F10104_USER=почта
set F10104_PASSWORD=пароль
python tools/probe.py tools/cases/consultations.py
```

По умолчанию бьёт в прод (`https://api.allkey.kz`). `--local` — в
`127.0.0.1:8000`. `--only ПУ-1,РОЯ-1` — прогнать выборочно.

Пароль в командной строке не пишем: он читается из переменных окружения.
Если токен уже есть — положите его в `F10104_TOKEN`, логин пропустится.

## Как добавить ситуацию

`tools/cases/consultations.py`, одна строка на ситуацию:

```python
("ПУ-1", "о чём консультация и откуда",
 case(country="TR", income="services", S3_4="construction", amount=50000.0),
 {"kpn.rate": 0.20, "flag:F-PE-RISK": True}),
```

Ожидания — четвёртый элемент, необязательный. При разборе консультации
ожидаемое часто становится понятно только после прогона, и пустая колонка
здесь честнее выдуманной.

Помощник `case()` заполняет обязательные ответы значениями по умолчанию.
Короткие имена: `country`, `income`, `amount`, `rate`, `act`, `paid`,
`currency`. Остальные ключи как в анкете, первая точка пишется
подчёркиванием: `S3_4`, `S5_5`, `S7_2`. `None` убирает ответ совсем —
так задаётся «акта ещё нет» или «оплаты не было».

Пути в ожиданиях — как в вердикте: `kpn.rate`, `kpn.amount_kzt`, `graphs.F`,
`date_rule.rule_id`, `vat.applicable`, `confidence`. Флаг — `flag:F-PE-RISK`.

## Как разбирать расхождение

Порядок один и тот же, и он не начинается с предположения, что права
помогайка:

1. ошиблась помогайка;
2. консультация опирается на прежний кодекс — ст. 644–648 утратили силу
   с 01.01.2026, и часть разъяснений в сети написана до этого;
3. случай за периметром первой версии.
