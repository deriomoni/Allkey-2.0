Как это подключается к сайту

Браузер не может обращаться к nationalbank.kz напрямую: сайт НБ РК не отдаёт заголовки CORS, запрос из фронтенда будет заблокирован. Поэтому загрузка идёт через бэкенд, который заодно кэширует результат — опубликованный курс за прошедшую дату не меняется никогда, тянуть его повторно бессмысленно.

Контракт эндпоинта, который ожидает этот интерфейс:

GET /api/rates?codes=USD,EUR&from=2026-06-01&to=2026-06-30

200 OK

Серверная реализация — файл nbrk-rates.js, зависимостей нет. Эндпоинты НБ РК: /rss/get_rates.cfm?fdate=ДД.ММ.ГГГГ за конкретную дату, /rss/rates_all.xml — последние опубликованные.
