# Задача для Claude Code — Кейс 2: Сверка актов взаиморасчетов

## Контекст

Второй кейс сервиса сверки — сравнение двух актов сверки взаиморасчетов между контрагентами. Каждая сторона формирует свой акт из своей 1С, нужно найти расхождения.

В папке `/reference` лежит `act_reconciliation.py` — рабочий код парсинга и сравнения.

## Особенности этого кейса

1. **Зеркальность дебет/кредит** — что у покупателя кредит (задолженность), у продавца дебет (дебиторка)
2. **Разные номера документов** — у каждого своя нумерация ("Поступление 00000003015" vs "Реализация 28")
3. **Сопоставление по: дата + сумма + тип операции** (не по номеру документа!)
4. **Строки со счетами-фактурами пропускаем** — они дублируют информацию

## Структура файла акта сверки

```
Row 0-5: Заголовок ("Акт сверки", период, контрагенты)
Row 6: "По данным [Компания], KZT"
Row 7: Заголовки таблицы (Дата | Документ | Дебет | Кредит)
Row 8: Сальдо на начало
Row 9+: Операции
```

**Колонки данных:**
- `row[1]` — дата (формат DD.MM.YY, например "08.01.25")
- `row[2]` — документ ("Поступление ТМЗ и услуг 00000003015 от 08.01.2025")
- `row[4]` — дебет
- `row[5]` — кредит

## Ключевые моменты парсинга

```python
# Читаем без заголовков
df = pd.read_excel(filepath, header=None)

# Ищем строки с датой
date_pattern = re.compile(r'^\d{2}\.\d{2}\.\d{2}$')

for idx, row in df.iterrows():
    cell_1 = str(row[1]).strip() if pd.notna(row[1]) else ''
    
    if not date_pattern.match(cell_1):
        continue
    
    doc = str(row[2]) if pd.notna(row[2]) else ''
    
    # ВАЖНО: пропускаем счета-фактуры
    if 'счет-фактура' in doc.lower():
        continue
    
    debit = float(row[4]) if pd.notna(row[4]) else 0
    credit = float(row[5]) if pd.notna(row[5]) else 0
```

## Логика сопоставления

```python
# Ключ для сравнения: дата + сумма + тип операции
def make_key(entry):
    return (entry.date, entry.amount, entry.op_type)

# Тип операции определяем по тексту документа
def get_op_type(doc):
    if 'поступление' in doc.lower() or 'реализация' in doc.lower():
        return 'товар'
    elif 'платежное' in doc.lower():
        return 'оплата'
    else:
        return 'прочее'
```

## Что НЕ делать

- Не сопоставлять по номеру документа — они разные у каждой стороны
- Не забывать пропускать строки со счетами-фактурами
- Не путать колонки (дата в col[1], не в col[0])
- Не использовать `header=0` — структура нестандартная
